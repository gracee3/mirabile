# Mirabile Control Cockpit Field Ledger

This is the completion ledger for every field in the ten canonical resource payloads and their
`ResourceEnvelope` values. “Visible” means the field is mounted in the control manifest; immutable
identities and repository-owned clocks are deliberately projected as read-only text. All editable
rows cross the web boundary as typed `AppIntent` / mutation enums. No row uses a field path, JSON
patch, CSS selector, pixel coordinate, or web-side repository write.

The browser evidence column names the required journey in `scripts/verify.sh`. The control manifest
constructor also rejects duplicate semantic addresses and supplies a nonempty reason for every
disabled descriptor. Stable draft row IDs are application-owned and never enter canonical payloads
or macro JSON.

## Deliberate persisted-only boundaries

- Query execution is not implemented. Query definitions and all AST variants are fully authorable,
  but no control claims execution.
- Derived chart calculation is not implemented. All recipe variants are fully authorable and
  durable, but provider execution remains unavailable with an explicit reason.
- Runtime rendering for non-wheel ViewObjects is not implemented. Their canonical definitions are
  fully authorable and durable.

These boundaries are capabilities outside the modeled persistence fields; they are registered in
`COCKPIT_COVERAGE` with nonempty unavailable reasons.
